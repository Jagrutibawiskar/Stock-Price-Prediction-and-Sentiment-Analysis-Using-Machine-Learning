# Stock-Price-Prediction-and-Sentiment-Analysis-Using-Machine-Learning

Project Overview

This project leverages sentiment analysis and machine learning models to predict stock prices. It integrates stock market data (using yfinance), news data (via NewsAPI), and sentiment analysis techniques (using VADER and BERT) to predict future stock prices. The goal is to assess how news sentiment can influence stock prices and predict their movements.

Technologies Used

Python: Programming language used for the project.
yfinance: Library for fetching historical stock data.
NewsAPI: API to fetch news articles about the stock (Apple in this case).
VADER Sentiment: Sentiment analysis library to analyze the polarity of news articles.
BERT (Hugging Face Transformers): For advanced sentiment analysis on news articles.
scikit-learn: For machine learning (linear regression, model evaluation).
Matplotlib/Plotly: For data visualization.
pandas: Data manipulation and analysis.
numpy: For numerical computations.
